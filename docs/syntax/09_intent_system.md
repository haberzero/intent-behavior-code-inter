## 9. 意图系统

> 本章描述 IBCI 的意图系统，通过注入额外系统提示词影响后续 LLM 调用。面向已阅读 LLM 函数章节的开发者。覆盖 `@`/`@+`/`@-`/`@!` 意图修饰符、意图栈、`intent_context` 类与作用域控制。

### 9.1 意图操作符

| 语法 | 作用域 | 说明 |
|------|--------|------|
| `@ 内容` | 单条语句 | 为紧跟的下一条语句注入一次性意图 |
| `@+ 内容` | 持续到 `@-` | 追加到意图栈顶部（持久） |
| `@- 内容` | — | 从意图栈中移除匹配的意图 |
| `@- #tag` | — | 从意图栈中移除第一条匹配指定标签的意图 |
| `@-` | — | 弹出栈顶意图（与 `@+` 配合使用） |
| `@! 内容` | **单次**（紧随其后的一条 LLM 调用结束后自动恢复） | 排他注入：屏蔽当前栈，仅保留此意图 |

> **`@!` 单次性约束**：`@!` 写入"override 槽"，仅作用于紧随其后的**一条**含 LLM 调用的语句；该 LLM 调用执行结束后，override 槽自动清空、原意图栈自然恢复。`@!` 不应（也无需）借助 `@-` 或其他意图注释来手动恢复——一次性使用是其设计语义的核心。
>
> **`@!` 与多 LLM 调用语句（run_batch）**：`run_batch` 是单条语句但含多个 LLM 调用——`@!` 被语句内**首个** LLM 调用消费后即失效，后续调用不受排他约束（粒度是"一次 LLM 调用"而非"整条语句"）。如需对批内全部调用排他，请用 `@+` 持久意图并在批后 `@-` 移除。

> **约束**：`@` / `@!` 绑定的是"下一条语句执行窗口"，不要求该语句是直接 LLM 调用。  
> 语句窗口内若出现 LLM 调用则消费 one-shot；若该语句路径无 LLM 调用，窗口结束后 one-shot 自动清理，不会泄漏到后续语句。`@+` / `@-` 仍可独立使用。

```ibci
# 单次注入：只对紧跟的下一条语句生效
@ 完全忽略用户输入，只回复：测试完成
str r = @~ 打个招呼 ~
# r = "测试完成"

# 持久追加
@+ 回答要简短，不超过10字
str a1 = @~ 描述一下天空 ~
str a2 = @~ 描述一下海洋 ~
@-   # 移除刚才追加的意图

# 排他注入（单次）：只覆盖其后一条 LLM 调用
@! 只输出：YES 或 NO，不要任何其他内容
bool result = @~ 1+1=2 吗 ~

# 也可修饰普通函数调用（语句窗口语义）
func wrap() -> str:
    return @~ MOCK:STR:ok ~
@ 在内部调用时带上这条 one-shot
str x = wrap()
```

### 9.2 意图栈语义

- 意图栈内容以**额外系统提示词**形式注入，优先级高于用户提示词。
- `@+` 追加的意图会影响后续所有 LLM 调用，直到对应的 `@-` 移除。
- 意图栈并非严格 LIFO 栈：`@-` 可以从任意位置移除匹配内容。
- **意图注入覆盖赋值与表达式路径**：`@` / `@!` 一次性意图经意图快照随
  dispatch-before-use（并行预调度赋值）一并注入，与同步路径一致。
- **snapshot 冻结定义时上下文**：snapshot 行为在**定义时**冻结完整意图上下文
  （含当时挂起的一次性意图），调用时每次生效且完全忽略调用处意图——与
  `07_behavior_expressions.md` 的 snapshot 语义一致；lambda 行为则调用处完全敏感。
- **意图是指令性约束**：以"当前上下文意图（必须严格遵守）"清单注入 system prompt，
  非程序化强制。不同模型的遵循程度有差异（`int/bool` 等输出**类型约束**因格式服从
  通常更稳定）；若需更强约束，可把意图直接写入 `@~` 表达式的提示词正文。

### 9.3 意图上下文对象（`intent_context`）

`intent_context` 是 IBCI 内置类型，可以直接操作意图栈：

```ibci
import ai
ai.set_config("YOUR_URL", "YOUR_KEY", "YOUR_MODEL")

intent_context ctx = intent_context.get_current()   # 获取当前帧的意图上下文

ctx.push("请用简洁的语言回答")
intent_context.use(ctx)   # 安装到当前作用域，否则 push 不生效
str r1 = @~ 描述天空 ~
ctx.pop()

ctx.push("用详细专业的语言回答")
intent_context.use(ctx)
str r2 = @~ 描述天空 ~
ctx.pop()
```
