# 04 · 用意图控制 LLM 行为

> 本章是 IBCI 意图系统的入门教程。面向已掌握行为表达式（`@~ ... ~`）基础的 IBCI 用户。覆盖四种意图操作符的实战用法、函数调用中的意图隔离机制、以及 `intent_context` 对象的程序化控制。

## 意图的定义

**意图**是注入到 LLM 调用中的额外系统提示词。它不是直接写在 `@~` 里的用户提示词，而是附着在语句上的"元指令"——告诉 LLM 如何回答、用什么风格、遵循什么约束。

```ibci
import ai
ai.set_config("https://api.example.com", "YOUR_KEY", "gpt-4o")

@ 请用 JSON 格式回复
str data = @~ 描述今天的天气 ~
```

上面 `@ 请用 JSON 格式回复` 不会直接出现在用户提示词中，而是作为系统级约束注入到紧跟着的那一条 LLM 调用里。

## 四种意图操作符

| 操作符 | 作用域 | 典型场景 |
|--------|--------|----------|
| `@ 内容` | 紧跟的下一条语句 | 一次性格式/语言约束 |
| `@+ 内容` | 持续到 `@-` 移除 | 对话风格、角色设定、回答长度限制 |
| `@- 内容` / `@-` | 移除指定意图 / 弹出栈顶 | 恢复默认行为 |
| `@! 内容` | 紧随的一条 LLM 调用（自动失效） | 临时屏蔽所有已有意图、精确控制单次输出 |

语法完整定义见 [语法参考 / 意图系统][syntax-09]。

### @+ 和 @-：持久意图栈

持久意图影响后续所有 LLM 调用，直到显式移除。适合"整段对话都用中文"这类需求：

```ibci
@+ 始终用中文回复
@+ 回答控制在 20 字以内

str a1 = @~ 描述天空 ~
str a2 = @~ 描述海洋 ~

@-                         # 弹出栈顶："回答控制在 20 字以内"
@- 始终用中文回复           # 移除指定意图
```

### @：一次性临时约束

`@` 只对紧跟的下一条语句生效，执行后自动消失。适合"这一次用英文回答"的场景：

```ibci
@+ 始终用中文回复

str r1 = @~ 介绍北京 ~      # 中文回复

@ 这次用英文
str r2 = @~ 介绍北京 ~      # 英文回复

str r3 = @~ 介绍上海 ~      # 中文回复（@ 已失效）
```

### @!：排他覆盖

`@!` 屏蔽当前意图栈中所有意图，**仅**注入 `@!` 自身的内容，且只在紧随的一条 LLM 调用中生效。适合"无论之前有什么约束，这一条我只想要纯数据"：

```ibci
@+ 始终用中文回复
@+ 回答控制在 20 字以内

@! 只输出：YES 或 NO，不要任何其他内容
bool result = @~ 1+1=2 吗 ~
# result 只会是 1 或 0，不受中文/20字等约束影响
# @! 在此处已自动失效，无需手动 @-

str next = @~ 描述天空 ~
# next 恢复中文 20 字以内的回答
```

## 函数调用中的意图隔离

每个函数调用在进入时会**从调用者帧 fork 一份意图上下文副本**。函数内部对意图的修改仅影响该副本，函数返回后调用者的意图上下文不受任何影响。

```ibci
func ask_in_english() -> str:
    @+ 用英文回复
    str answer = @~ 介绍北京 ~
    @- 用英文回复
    return answer

import ai
ai.set_config("URL", "KEY", "model")
@+ 始终用中文回复

str r1 = @~ 今天的问候 ~           # 中文
str r2 = ask_in_english()           # fork 意图→内部英文→返回后不受影响
str r3 = @~ 明天的问候 ~           # 中文（调用者的意图栈未变化）
```

这种帧级隔离保证意图不会跨函数泄漏——你不需要在调用前手动保存意图、调用后手工恢复。

### clear_inherited：从零开始的意图上下文

某些函数需要完全不继承调用者的意图，在"纯净"的上下文中运行：

```ibci
func pure_fact_query() -> str:
    intent_context ctx = intent_context.get_current()
    ctx.clear_inherited()
    str answer = @~ 1+1 等于几？只回答数字 ~
    return answer
```

`clear_inherited()` 清空当前帧从调用者继承的全部意图，函数内部从一片空白开始。

### use：切换自定义意图上下文

你可以预先构建一个独立的意图上下文对象，在函数内部用 `use()` 切换到它：

```ibci
intent_context strict_ctx = intent_context.get_current()
strict_ctx.push("只输出纯数字，不要任何其他文字")

func strict_number(str question) -> int:
    intent_context ctx = intent_context.get_current()
    ctx.use(strict_ctx)
    int answer = @~ $question ~
    return answer

import ai
ai.set_config("URL", "KEY", "model")

@+ 用详细专业的语言回答
int result = strict_number("1+5 等于多少")   # 只输出 "6"，忽略"详细专业"
```

`intent_context` 的完整 API 详见 [语法参考 / 意图系统][syntax-09]。

## 意图优先级与消解

当多个意图同时存在时，LLM 调用的最终系统提示词按以下优先级组装：

1. `@!` 排他意图（最高优先级，且会屏蔽所有其他意图）
2. `@` 一次性意图（合并入本次调用后清除）
3. 意图栈内容（`@+` 持久意图，按栈序合并）
4. 全局意图
