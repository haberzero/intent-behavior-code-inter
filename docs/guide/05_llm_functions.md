# 05 · 定义和使用 LLM 函数

> 本章是 IBCI LLM 函数的入门教程。面向已掌握行为表达式和意图系统的 IBCI 用户。覆盖 `llm ... llmend` 语法、`__sys__`/`__user__` 提示词段、参数插值与 `__llmretry__` 重试提示。

---

## 你将会学到

- 将提示词逻辑封装为可复用的命名 LLM 函数
- 区分 `__sys__`（角色设定）和 `__user__`（具体任务）
- 在提示词中安全地插入变量
- 用 `__llmretry__` 处理 LLM 输出解析失败

前提：你已完成 [04 · 用意图控制 LLM 行为][] 的学习，能在 IBCI 中管理意图上下文。

---

## 为什么用 LLM 函数

直接在代码中写 `@~ ... ~` 行内行为表达式在简单场景中足够好用，但当你需要：

- 在多处用同一套提示词逻辑调用 LLM
- 接受参数定制每次调用的输入
- 明确定义系统提示词与用户提示词的边界
- 集中管理重试策略

就应该将提示词逻辑封装为 **LLM 函数**。

```ibci
# 行内方式：每次都要完整写提示词，无法复用
str r1 = @~ 请将 "hello" 翻译为中文 ~
str r2 = @~ 请将 "world" 翻译为中文 ~
# ...
```

```ibci
# LLM 函数：定义一次，任意调用
str r1 = 翻译("hello", "中文")
str r2 = 翻译("world", "中文")
```

---

## 基本语法

```ibci
llm 翻译(str 文本, str 目标语言) -> str:
__sys__
你是一个专业翻译，直接输出翻译结果，不加任何解释。
__user__
请将 "$文本" 翻译为 $目标语言。
llmend
```

关键规则：
- 关键字 `llm` 开头，`llmend` 结束
- `__sys__` 块：系统提示词（设定角色、风格、约束）
- `__user__` 块：用户提示词（具体任务，支持 `$变量名` 插值）
- 函数体**不需要缩进**——顶格书写，否则缩进空格会被当作提示词内容

LLM 函数的完整语法参考 [语法参考 / LLM 函数][syntax-08]。

---

## `__sys__` vs `__user__`

两者在 LLM 函数内部分工明确：

| 块 | 语义 | 放在里面的是 |
|----|------|-------------|
| `__sys__` | 系统提示词 | 角色、能力边界、输出格式约定、回答风格 |
| `__user__` | 用户提示词 | 具体任务描述、输入数据、参数化内容 |

```ibci
llm 总结要点(str 文章) -> str:
__sys__
你是一个专业编辑，善于提炼文章核心观点。
只输出要点列表，每条一行，格式为 "- 要点"。
__user__
请总结以下文章的核心要点：

$文章
llmend
```

`$文章` 在 `__user__` 块中会被替换为调用时传入的实际参数值。

---

## 参数插值

`__user__` 块中的 `$变量名` 会被替换为对应参数在调用时的值。插值规则：

- 参数名**严格区分大小写**
- 每次调用时独立求值，不缓存
- 参数类型决定了插值方式——`str` 直接替换文本，自定义类型则调用其 `__to_prompt__()` 方法

```ibci
llm 打分(str 商品名, int 最高分) -> int:
__sys__
你是一个商品评价专家。
__user__
请给 "$商品名" 打分，范围 1 到 $最高分，只返回整数。
llmend

int score1 = 打分("机械键盘", 10)    # 评分范围 1-10
int score2 = 打分("无线耳机", 5)     # 评分范围 1-5
```

## `__llmretry__`：重试提示词注入

LLM 输出不一定能成功解析为目标类型。当 `__from_prompt__` 解析失败触发重试时，`__llmretry__` 块的内容会作为额外系统提示词注入到重试调用中：

```ibci
llm 提取年龄(str 文本) -> int:
__sys__
你是一个信息提取专家。
__user__
从以下文本中提取年龄，只返回数字：

$文本
__llmretry__
请务必只返回一个纯整数，不要附带任何文字、标点或单位。
llmend
```

当 `__user__` 中的 `$文本` 为 "我今年 25 岁" 时，LLM 应返回 `25`。如果 LLM 返回了 `25 岁`，解析为 `int` 失败，触发重试——此次重试会额外收到 `__llmretry__` 中定义的提示词。

`__llmretry__` 只在 LLM 函数的重试中生效，不影响行内 `@~ ... ~` 的重试（行内重试由 `llmexcept` + `retry` 控制，见 [语法参考 / 健壮性][syntax-10]）。

---

## 调用 LLM 函数

LLM 函数的调用方式与普通 IBCI 函数完全相同：

```ibci
import ai
ai.set_config("https://api.example.com", "YOUR_KEY", "gpt-4o")

llm 翻译(str 文本, str 目标语言) -> str:
__sys__
你是一个专业翻译，直接输出翻译结果。
__user__
将 "$文本" 翻译为 $目标语言。
llmend

str zh = 翻译("Hello, how are you?", "中文")
str ja = 翻译("Hello, how are you?", "日文")

print(zh)
print(ja)
```

LLM 函数同样支持 `snapshot` / `lambda` 封装、作为高阶函数参数传递、以及 `fn` 引用绑定。
