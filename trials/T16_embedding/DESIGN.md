# T16 · 词嵌入一等能力试用套件

## 范围

embedding 一等能力（PT-FEAT-16）的语言面行为基线：`vector` 值类型方法面、
`ai.embed` 动态重载、`ai.retrieve` 检索最小闭包、配置/错误/值语义面。

## 用例矩阵

| 用例 | 面 | LLM |
|------|-----|-----|
| T16-EMB-M1 | mock 单文本 → vector | 否 |
| T16-EMB-M2 | mock 批量保序（顺序绑定） | 否 |
| T16-EMB-M3 | mock 检索 top-k + 自参考相似度 | 否 |
| T16-EMB-M4 | vector 方法面 + 返回类型锁定 | 否 |
| T16-EMB-M5 | 值语义（相等/不可修改/字典键排除） | 否 |
| T16-EMB-M6 | 错误面 fail-fast（dim 失配/非数值元素） | 否 |
| T16-EMB-L1 | 真实单文本 embed（SiliconFlow） | 是 |
| T16-EMB-L2 | 真实语料召回（自参考 top-1） | 是 |

## 断言纪律

- mock 用例确定性（MOCK:VEC 哈希派生——零网络零 key，可重复断言）；
- 真实用例断言语义性质（维度 > 0 / 自参考相似度 ≈ 1.0 / 召回命中数），
  不断言具体向量值（端点输出非确定面豁免——相对测量纪律）；
- 检索粒度 = 语料级候选召回（相对测量），非单句级语义判定。
