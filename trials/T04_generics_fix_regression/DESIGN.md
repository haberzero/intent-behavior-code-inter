# T04_generics_fix_regression — 泛型修复回归试用

> **试用与记录任务，不是修复任务**。目标：对泛型缺陷四项修复
> （G1 方法体类型参数 / G2 自引用字段 / BOUNDARY-G1 非法实参 / 双通道 descriptors）
> 做**针对性回归试用**，重点验证修复正确性、边界、正交交互，找修复引入的隐性问题。
> 发现的缺陷只记录、登记，不在本任务修复。

## 一、背景

泛型缺陷四项修复已通过 e2e 回归；本任务对修复成果做独立压力/恶意试用，
对齐既有 T03 方法论。

## 二、工作模式与硬约束（沿用）

| 约束 | 内容 |
|------|------|
| 死循环保护 | 每例经 OS 进程级硬超时（SIGKILL 进程组）兜底；harness 无超时不运行 |
| 记录优先 | 只记录登记，不改内核代码；文件化确定性记录（logs/ + register.jsonl + REGISTER.md） |
| 禁 push | 全程本地 commit |

> 纯编译/运行时语法试用（mock 模式，无真实 LLM）。所有用例无超时不运行。
